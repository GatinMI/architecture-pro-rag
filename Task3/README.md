# Задание 3. Векторный индекс базы знаний

## Модель эмбеддингов

**all-MiniLM-L6-v2** — [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2),
та же, что и в Задании 1. Локальный инференс через `sentence-transformers`, CPU.
Размер эмбеддинга: **384** измерения, L2-нормализованные; поиск — косинусная
близость (FAISS `IndexFlatIP` на нормализованных векторах, решение Задания 1).


## Что индексировали

Базу из Задания 2: `Task2/knowledge_base/docs/` — 56 документов,
~1,13 млн слов о вымышленной вселенной (Aetheri, Synth Flux, Kael Drayden).

## Как режется на чанки

Цель — чанки 100–300 слов, логически связанные (не рваные посреди
мысли). Схема в `build_index.py`:

1. документ режется по **H2-секциям** — чанк никогда не склеивает две
   разные секции;
2. секция короче 100 слов сливается с предыдущей (иначе получаются
   чанки-осколки типа голого подзаголовка);
3. внутри секции `RecursiveCharacterTextSplitter`
   (langchain-text-splitters, размер считается в словах) режет по абзацам —
   текст вики состоит из коротких параграфов по 90–160 слов, поэтому
   абзацы **упаковываются** в чанки до 200 слов (не больше 300);
4. хвост секции короче 100 слов вливается в предыдущий чанк,
   повторяющийся кусок пересечения при этом вырезается.

У каждого чанка метаданные для цитирования ботом:

| поле | что это |
|---|---|
| `id` | `<файл>#<n>`, например `Anakin-Skywalker#451` |
| `doc` | файл: `Anakin-Skywalker.md` |
| `title` | заголовок статьи (H1): «Kael Drayden» |
| `section` | H2-секция: «Biography» |
| `word_start` | смещение в словах от начала файла (приближённо — см. ниже) |
| `text` | сам текст чанка |

`word_start` — с погрешностью: H2-заголовки не входят в текст секций,
поэтому смещение «плывёт» на несколько слов на каждую секцию. Для цитирования
(«файл → секция → место») этого достаточно; проверил по 621 случайному чанку —
все совпадают с реальным местом в файле с точностью ±40 слов.

## Как пользоваться

```bash
# пересобрать индекс
.venv/bin/python Task3/build_index.py

# поиск (по умолчанию топ-3)
.venv/bin/python Task3/query_index.py "кто такой Kael Drayden?"
.venv/bin/python Task3/query_index.py "что такое Synth Flux?" -k 5
```

## Проверка качества

Четыре запроса в `index/search_examples.txt` — три «как спросил бы пользователь»
(по-русски) и контрольный на языке корпуса:

* **«что такое Synth Flux?»** — топ-3 это статья The-Force.md («Synth Flux»),
  определение в первом же чанке;
* **«что произошло в битве при Mossfell?»** — вторая строчка — статья
  Battle-of-Endor.md («Battle of Mossfell»), в топе и статьи-соседки,
  которые описывают последствия битвы;
* **«кто такой Kael Drayden?»** — топ-3 все про самого Drayden,
  его страница (Anakin-Skywalker.md) в топ-3;
* контрольный **«Aetheri Knight from Dunemere»** — на языке корпуса
  страница персонажа поднимается в топ-2.
