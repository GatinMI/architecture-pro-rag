# Задание 4. RAG-бот с техниками промптинга

## Что это

Бот отвечает на вопросы о вселенной Aetheri, опираясь только на базу знаний
из Заданий 2–3 (56 статей, FAISS-индекс). Тот же код работает в двух
интерфейсах: консоль (`cli.py`) и Telegram (`bot.py`).

## Как устроен пайплайн

Каждый запрос проходит 5 шагов (`Task4/rag/pipeline.py`):

```
вопрос пользователя (на его языке)
   │
   1. переформулирование на язык корпуса (англ.) — быстрый вызов LLM;
   │    если вопрос уже на латинице — пропускается
   │
   2. эмбеддинг тем же MiniLM, что и при индексации → поиск топ-5 в FAISS
   │
   3. проверка порога: лучший фрагмент далек по смыслу (cos < 0.40)?
   │    → «Не знаю» и выход (LLM не вызывается)
   │
   4. сборка промпта: system (CoT + few-shot) + контекст (5 фрагментов
   │    с источниками: файл, статья, секция, близость) + вопрос
   │
   5. LLM (Qwen3.8-27B через OpenAI-совместимый API) → ответ:
        сначала 2–4 шага рассуждения, затем «Ответ: ...»
```

Почему нужен шаг 1: корпус на английском, а пользователь пишет по-русски,
и MiniLM не переводит. Без
переформулирования на русском запросе «шумные» слова не несут смысла и
поиск работает плохо.

## Модули

| файл | роль |
|---|---|
| `rag/config.py` | настройки из `.env` (URL/ключ/модель LLM, порог, top-k) |
| `rag/llm.py` | вызов OpenAI-совместимого API; повтор с удвоенным бюджетом, если «размышления» съели весь max_tokens |
| `rag/retriever.py` | загрузка FAISS-индекса + `chunks.jsonl` из Задания 3, поиск |
| `rag/prompt.py` | few-shot примеры + CoT-указание + фрагменты с метаданными |
| `rag/pipeline.py` | связывает всё вместе, решает «отвечать / не знаю» |
| `cli.py` | консольный интерфейс (интерактив или один запрос из аргументов) |
| `bot.py` | Telegram-бот на aiogram 3 |
| `few_shot_examples.json` | примеры для few-shot (вопрос, ответ, откуда взяты) |

## Few-shot

Два примера в system-промпте — не придуманы «из головы»: по каждому
вопросу был выполнен реальный поиск по базе, и LLM сгенерировала ответ
по найденным фрагментам (источники записаны в `few_shot_examples.json`):

* «Что такое HyperRelay?» → Hyperdrive.md · «Hyperrelay» · «Operation»;
* «Кто такой Zho?» → Yoda.md · «Zho» · «Powers and abilities».

Примеры задают формат ответа (шаги → «Ответ:»), язык — русский.

## Chain-of-Thought

В system-промпте: «Сначала размышляй, потом отвечай: напиши 2–4 коротких
шага, как искал ответ, а затем на отдельной строке "Ответ:" и сам ответ».
Пошаговое рассуждение видно в каждом ответе — см. `dialogs/`.

## «Не знаю»

Два слоя:

1. **до LLM** — порог по косинусной близости. Замерил на реальных
   запросах: вопросы из базы дают лучший cos 0.49–0.73, вопросы вне базы —
   не выше 0.33. Порог 0.40 разрезает зазор. Ниже порога бот сразу отвечает
   «Не знаю» и не тратит вызов LLM;
2. **в промпте** — правило: «Если во фрагментах нет ответа на вопрос,
   напиши "Ответ: Не знаю — в базе знаний этого нет."». Ловит случай, когда
   фрагменты по теме нашлись, но конкретного факта в них нет.

Примеры: `dialogs/не_знаю_06.md` (футбол — тема вне базы),
`dialogs/не_знаю_07.md` (цена корабля — факт не в базе).

## Как запустить

```bash
# консоль: интерактивно
.venv/bin/python Task4/cli.py
# консоль: один запрос
.venv/bin/python Task4/cli.py "кто такой Pip?"

# Telegram: токен и (опционально) прокси — в .env
#   BOT_TOKEN=...
#   TELEGRAM_PROXY=socks5://localhost:2080   # если Telegram недоступен напрямую
.venv/bin/python Task4/bot.py
```

Настройки LLM (URL, ключ, модель) — в `.env` в корне репозитория
(в git не коммитится).
