# Задание 2. База знаний

## Какой мир внутри

В базе — вымышленная вселенная: галактика, где после распада республики
возник Imperium, а на стороне повстанцев — Free Coalition.
Есть тайный орден Aetheri, который работает с «Synth Flux», дроиды-
протоколы (Astra-9, Bolt-3), боевые дроиды, звёздные корабли
(Void Core, Corsair Wing), планеты (Dunemere, Vantor, Mossfell) и война
между всем этим. Ключевые персонажи: Kael Drayden (и его сын Joren),
Elira Solen, Dax Karrick, Theron Mal, Orien Kade, Zho, Nyla.

По стилю это «классическая» космическая опера — орден рыцарей, тёмная
сторона, империя и повстанцы — но ни одно имя, планета, корабль и фильм
не совпадают с чем-либо реальным.

## Где текст и как его переименовали

Задание требует, чтобы LLM не знала мир по памяти, поэтому исходные
тексты взяты из открытой фандом-вики (starwars.fandom.com, 56 страниц:
персонажи, планеты, битвы, фракции, техника), а вся ключевая терминология
заменена на вымышленную.

Цепочка такая:

1. `scripts/download_wiki.py` — качает страницы через MediaWiki API
   (`action=parse`) и чистит HTML: выкидывает инфобоксы, навигационные
   шаблоны, оглавление, дизамбиги, сноски и хвостовые секции
   (Appearances / Sources / Notes / References). Результат — сырой текст
   в `raw/` (56 `.md`, один файл — одна сущность).
2. `scripts/rename_terms.py` — подменяет термины по двум словарям:
   * `knowledge_base/terms_map.json` — 606 записей, подмена без учёта
     регистра (персонажи, планеты, расы, техника, фильмы, продакшен —
     да, и фамилии актёров тоже, чтобы не светить происхождение);
   * `knowledge_base/terms_map_case.json` — 18 записей, подмена строго
     с учётом регистра. Сюда вынесены слова, которые в нижнем регистре —
     обычные английские: tie/ties (завязывать), trace (след), solo
     (solo-миссия), bane (бедствие), grievous (тяжкий), ghost, rogue,
     driver, wood, omega, se (в «per se»!). Иначе «TIE» ломало бы
     «to tie up», а «Bane» — «a bane to the regime».
3. Правила подмены: сначала длинные термины (фразы раньше слов — «C-3PO»
   раньше «3PO»), границы — по латинице/цифрам (Vader's подменяется,
   Reykjavik нет), регистр отражается на замену: «The Force» → «Synth
   Flux», «the force» → «synth flux», всё в верхнем — в верхнем.
4. Пост-обработка: артикли («a Jedi» после замены даёт «a Aetheri» —
   скрипт чинит на «an Aetheri», и наоборот «an R2» → «a Bolt-3») и
   маленький фикс-лист на разовые артефакты.
5. Самопроверка: по окончании скрипт прогоняет готовый текст по всем
   624 исходным терминам и печатает остатки. Остатков нет — ни один
   исходный термин в базе не сохранился.

Плюс отдельный аудит `scripts/audit_caps.py`: собирает все токены с
заглавной, которых нет в словарях, и смотрит по частоте. Прогонял
повторно до тех пор, пока в топ не остались только новые имена и обычные
английские слова (General, Senate, Episode…). Так поймал ещё пару десятков
«пробитых» имён (Sana Starros, Jocasta Nu, Wilhuff Tarkin, 4-LOM,
Grievous и т.д.).

## Числа

* 56 файлов, 1 130 887 слов;
* 624 термина в словарях (606 ci + 18 с учётом регистра), подменилось
  600, всего замен ~112 тыс.;
* в среднем ~20 тыс. слов на документ.

## Как проверить

```bash
# пересобрать базу из raw/ — результат побуквенно идентичен текущему
.venv/bin/python Task2/scripts/rename_terms.py

# аудит: токен с заглавной, которого нет в словарях (порог 6)
.venv/bin/python Task2/scripts/audit_caps.py 6
```

И самый простой способ: открыть любой файл из `knowledge_base/docs/`
и поискать любое исходное имя — Vader, Yoda, Tatooine, C-3PO, Empire.
Найдётся 0.
